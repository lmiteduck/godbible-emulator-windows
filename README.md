# 갓바이블 QA 에뮬레이터 (윈도우)

맥에서 화면 캡처와 QA에 쓰던 에뮬레이터 환경을 윈도우에서 그대로 쓰도록 묶은 것이에요.
안드로이드 스튜디오를 깔지 않아도 되고, 필요한 것은 모두 이 폴더 안에만 깔려요.

- 기기: 안드로이드 14 (Google Play 포함) · 화면 1080 × 2340 · 기준 360 × 780dp
- 맥에서 쓰던 것과 같은 판의 에뮬레이터 · adb를 받아요
- 아직 윈도우 실기에서 돌려 보지 못한 첫 판이에요. 막히면 `doctor.bat` 결과를 보내 주세요

## 준비물

| 항목 | 필요한 것 |
|---|---|
| PC | 윈도우 10 또는 11, 64비트 (ARM PC는 안 돼요) |
| 메모리 | 8GB 이상 (16GB 권장) |
| 디스크 | 여유 12GB 이상 |
| 가상화 | 켜져 있어야 해요. 아래 "문제가 생겼을 때 > 가속" 참고 |
| 계정 | QA용 구글 계정, 갓바이블 테스트 계정 (이 저장소에는 적지 않아요) |

## 설치 (한 번만)

1. 이 저장소를 내려받아요. [여기를 누르면 zip으로 받아져요](https://github.com/lmiteduck/godbible-emulator-windows/archive/refs/heads/main.zip). (또는 위쪽 초록색 **Code** 버튼 → **Download ZIP**)
   받은 zip을 `C:\godbible-emulator` 처럼 **영문이고 띄어쓰기 없는 경로**에 풀어요.
2. `setup.bat` 을 더블클릭해요. 약 2GB를 받아요. 회선에 따라 10~30분 걸려요.
3. 끝에 "설치가 끝났어요"가 나오면 돼요. 중간에 끊기면 다시 실행하면 이어서 받아요.

## 매번 쓰는 법

1. `start.bat` 을 더블클릭해요. 폰 모양 창이 뜨고 "준비됐어요"가 나올 때까지 기다려요.
2. 처음 한 번: 에뮬 화면에서 Play 스토어에 QA용 구글 계정으로 로그인하고 **갓바이블**을 설치해요.
   QA 빌드(apk)를 받았다면 `gb.bat install 파일경로` 로 깔아요.
3. 앱을 열고 테스트 계정으로 로그인해요.
4. 끝나면 `stop.bat` 으로 끄거나 에뮬 창을 닫아요.

## 명령 (`gb.bat`)

이 폴더에서 명령 창(주소 줄에 `cmd` 입력)을 열고 써요.

| 명령 | 하는 일 |
|---|---|
| `gb help` | 명령 목록 |
| `gb doctor` | 설치 · 가속 · 기기 · 앱 버전 상태 |
| `gb app` | 깔려 있는 갓바이블 앱 이름과 버전 |
| `gb install <apk>` | QA 빌드 깔기 |
| `gb shot <이름>` | 화면 찍기. `out\shots\날짜\이름.png` 와 360 폭 사본 |
| `gb rec <이름> [초]` | 화면 녹화 (기본 20초). `out\rec\` |
| `gb logs <이름>` | 지금까지의 로그 저장. `out\logs\` |
| `gb texts` | 화면에 보이는 글과 누를 수 있는 곳 목록 |
| `gb tap "<글>"` | 그 글이 있는 곳 누르기 |
| `gb tapxy <x> <y>` | 좌표 누르기 (px) |
| `gb swipe up` / `down` | 화면 넘기기 |
| `gb back` | 뒤로 |
| `gb ime on` / `off` | 한글 입력용 키보드로 바꾸기 / 되돌리기 |
| `gb type "<글>"` | 글 넣기 |
| `gb density` | 화면 기준을 360 × 780으로 다시 맞추기 |
| `gb stop` | 에뮬레이터 끄기 |

### 한글을 넣을 때

에뮬 화면의 키보드로 직접 쳐도 되지만, 명령으로 넣을 때는 순서가 있어요.

1. `gb ime on`
2. 에뮬 화면에서 입력할 칸을 눌러요 (키보드를 바꾸면 칸 선택이 풀려서 꼭 이 순서예요)
3. `gb type "넣을 글"`
4. `gb ime off` (되돌리지 않으면 캡처에 "ADB Keyboard" 띠가 찍혀요)

## QA할 때 지킬 것

테스트 계정이라도 실제 서버에 닿아요. 아래는 담당자와 정한 경우에만 눌러요.

- **돈 · 달란트가 움직이는 것**: 결제하기, 구매하기, 선물하기, 충전하기, 환불, 기부 완료하기, 출금
- **되돌릴 수 없는 것**: 탈퇴, 삭제, 계정 정보 변경 저장
- **밖으로 나가는 것**: 인증번호 받기(문자 발송), 공유하기, 초대 보내기, 문의 보내기
- **다른 사용자에게 보이는 것**: 글 · 댓글 등록, 좋아요 · 기도, 커뮤니티 가입 · 탈퇴, 신고

캡처와 로그에는 전화번호, 닉네임, 이메일, 추천인 코드, 다른 사용자 이름이 들어갈 수 있어요.
밖으로 보낼 때는 가리고, 로그인 정보는 어디에도 적지 않아요.

버그를 적는 양식은 [docs/bug-report.md](docs/bug-report.md) 에 있어요.

## 문제가 생겼을 때

먼저 `doctor.bat` 을 실행해요. 결과가 `doctor-result.txt` 로 저장되니 그 파일을 담당자에게 보내 주세요.

### 가속 (가장 흔해요)

`setup.bat` 끝이나 `gb doctor` 에서 가속을 쓸 수 없다고 나오면 에뮬레이터가 켜지지 않거나 아주 느려요.

1. 시작 메뉴에서 "Windows 기능 켜기/끄기"를 열어요.
2. **Windows 하이퍼바이저 플랫폼**과 **가상 머신 플랫폼**을 체크하고 재부팅해요.
3. 그래도 안 되면 PC의 BIOS에서 가상화(Intel VT-x 또는 AMD SVM)가 꺼져 있는 거예요. 회사 PC라면 IT 담당자에게 요청해 주세요.

### 그 밖

| 증상 | 해 볼 것 |
|---|---|
| `setup.bat` 이 바로 닫혀요 | 폴더 경로에 한글 · 띄어쓰기가 있는지 확인. `C:\godbible-emulator` 로 옮겨요 |
| 받다가 멈춰요 | `setup.bat` 을 다시 실행해요. 이어서 받아요 |
| 창은 떴는데 까만 화면이에요 | 3~5분 더 기다려요. 처음 켤 때는 오래 걸려요 |
| "켜져 있는 에뮬레이터가 없어요" | `start.bat` 을 먼저 실행해요 |
| 화면 크기가 달라 보여요 | `gb density` |
| 보안 프로그램이 막아요 | 이 폴더를 예외로 넣거나 IT 담당자에게 요청해요 |
| 다시 처음부터 깔고 싶어요 | `sdk`, `avd`, `android_home` 폴더를 지우고 `setup.bat` (`dl` 을 남기면 다시 받지 않아요) |

## 폴더

| 폴더 · 파일 | 내용 |
|---|---|
| `setup.bat` · `start.bat` · `stop.bat` · `doctor.bat` · `gb.bat` | 더블클릭하거나 명령 창에서 쓰는 파일 |
| `scripts\` | 실제로 일하는 PowerShell 스크립트 |
| `docs\` | 버그 양식 |
| `AGENTS.md` | AI 도구로 에뮬을 조작할 때의 규칙 |
| `sdk\` · `avd\` · `android_home\` · `dl\` | 설치하면 생겨요. 깃에는 올리지 않아요 |
| `out\` | 캡처 · 녹화 · 로그가 쌓여요. 깃에는 올리지 않아요 |
