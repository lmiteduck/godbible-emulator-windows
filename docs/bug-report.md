# 버그 기록 양식

한 건에 하나씩 적어요. 직접 본 것만 적고, 추측은 "확인 필요"로 나눠 적어요.

| 항목 | 내용 |
|---|---|
| 제목 | 어디에서 무엇이 어떻게 되는지 한 줄 |
| 앱 버전 | `gb app` 결과 (versionName · versionCode) |
| 환경 | 윈도우 에뮬레이터 · 안드로이드 14 · 360 × 780 |
| 계정 상태 | 예: 교회 미인증, 통독 참여 중 (로그인 정보는 적지 않아요) |
| 재현 순서 | 1. … 2. … 3. … |
| 기대한 것 | |
| 실제로 된 것 | |
| 매번 되나요 | 항상 / 가끔 (몇 번 중 몇 번) |
| 캡처 · 녹화 | `out\shots\…` · `out\rec\…` 파일 이름 |
| 로그 | `out\logs\…` 파일 이름 (재현 직후에 `gb logs` 로 저장) |
| 심각도 | 진행 불가 / 기능 오류 / 화면 깨짐 / 문구 |

## 예시

| 항목 | 내용 |
|---|---|
| 제목 | 내 달란트 내역에서 "선물하기" 줄 끝에 null 이 보임 |
| 재현 순서 | 1. MY 2. 내 달란트 3. 사용 탭 |
| 기대한 것 | 받는 사람 이름이 보임 |
| 실제로 된 것 | "선물하기: … → null" 로 보임 |
